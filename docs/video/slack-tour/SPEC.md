# Remote Bob in Slack

GOAL: Follow one example from a channel request to a thread reply, then learn
attachments, cancellation, recurring reports, and the optional verification API.

OUTPUT: HyperFrames 0.9.26, 1920 x 1080, 30 fps, 110 seconds (3300 frames).
English-only on-screen copy. Silent, deliberately designed for README viewing
without audio. No paid services, real Slack messages, tokens, or live jobs.

LOOK: White #ffffff, ink #1d1c1d, teal #117a66, Slack aubergine #3f0e40,
channel blue #1164a3, user avatar yellow #e9c45b. No gradients or shadows.
Locally bundled Inter variable font. Titles 68 px, body 30 px, margins 120 px,
screen radius 8 px. Lucide icons are locally bundled, not redrawn.

OBJECTS: Reconstructed Slack channel and thread, clearly labelled illustrative
demo throughout; terminal commands copied from the documented configuration.
No claim that the demo output or scheduled work actually ran.

MOTION: Message arrival 0.25-0.55 seconds, power4.out for horizontal arrivals,
opacity for status replacement, chapter progress advances at each cut.
Titles remain still. Pauses are deliberate reading holds.

SHOTS:

| Seconds | Task |
| --- | --- |
| 0-10 | Remote Bob, example task and reply |
| 10-24 | Manifest, environment variable names, Compose, invite, Socket Mode |
| 24-37 | No mention required; thinking state becomes a thread answer |

| 72-87 | Self-contained recurring task, explicit UTC, delivery channel |
| 87-99 | Chat /jobs versus opt-in /run verification/retry |

BANNED: Private chat screenshots, real tokens, fabricated performance claims,
unlabelled mock execution, fake live test results, gradients, glow, drifting
titles, marketing hero, narration that implies execution.

QA: Inspect each scene midpoint, first frame, transitions, and decoded MP4.
Check duration, resolution, codec, browser errors, clipping and contrast.
